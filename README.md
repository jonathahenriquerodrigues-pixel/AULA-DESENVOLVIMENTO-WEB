# Desenvolvimento Web — Aula 2

Primeira versão do sistema acadêmico, desenvolvida em HTML. Inclui um painel com indicadores de exemplo e páginas de alunos, cursos, matrículas e usuários.

## Como abrir

Abra [aula2/index.html](aula2/index.html) no navegador e use o menu para visitar as páginas. Os dados são exemplos estáticos.
